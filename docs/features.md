# Features

- `.vel` Single File Components
- original Teloce syntax plus npm-style directive aliases
- reactive signals and computed state
- keyed loops and conditional rendering
- components, imports, props, slots, and lifecycle hooks
- events, forms, filters, plugins, and router support
- scoped CSS and CSS modules
- project builds, source maps, asset hashing, watching, and HMR workflows
- standalone runtime for server-rendered HTML

## Feature groups

**Authoring:** SFC sections, original Teloce syntax, npm-style aliases, local
components, props, slots, lifecycle hooks, and scoped CSS.

**Browser behavior:** signals, computed state, watchers, event modifiers,
forms, keyed loops, conditions, filters, plugins, and router state.

**Build and delivery:** project discovery, local import resolution, source maps,
asset copying, asset hashing, optional bundling, development watching, HMR, and
the standalone runtime.

The server framework is deliberately outside these features. Teloce does not
provide a database, authentication system, ORM, or Python request router.
