# Implementation roadmap

## Implemented foundation

- Project creation and JSON workspace persistence.
- Visual canvas with heading, text, button, and card insertion.
- Component selection, text editing, deletion, responsive desktop/mobile canvas, and undo/redo state.
- Deterministic `.vel`, CSS, Flaxon Python, requirements, Vercel, and project metadata generation.
- Real compiler-backed preview validation and ZIP export.
- PWA manifest, service worker, offline page, and install icon.

5. Diagnostics, tests, export, Git integration, and deployment workflows.
6. Templates, component libraries, plugins, accessibility checks, and collaboration.
