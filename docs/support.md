# Support

For a bug report, provide:

- Teloce-Py version;
- Python and browser versions;
- operating system;
- smallest `.vel` file that reproduces the issue;
- compiler diagnostics and expected behavior.

Run `python -m pytest` before opening an issue.

For compiler failures, include the smallest `.vel` source and the command that
was run. For runtime failures, include the generated asset URL, browser console
error, network response shape, and whether the failure happens with HMR
disabled. For framework failures, include the framework version and a minimal
route/template reproduction.
