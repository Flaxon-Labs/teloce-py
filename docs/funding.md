# Funding and support

Teloce-Py is open-source software under the MIT license. Use GitHub issues for reproducible bugs and include the `.vel` input, compiler version, Python version, and diagnostic output. Do not include secrets or private application data.

## Responsible support requests

Before requesting help, run the smallest reproduction with a clean virtual
environment and record:

- the exact Teloce-Py version;
- Python and operating-system versions;
- the framework and browser versions;
- the command used;
- the source component and expected result;
- the complete diagnostic without secrets.

Feature discussions should explain the user problem, the proposed API, its
impact on original Teloce syntax, npm compatibility, generated output, and
browser behavior. Security issues should be reported privately when they could
affect users or expose sensitive information.
