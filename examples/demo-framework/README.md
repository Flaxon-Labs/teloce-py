# MiniVel UI demo framework

This is the runnable companion to Lesson 14. It proves imported `.vel`
components can use props, custom events, slots, scoped CSS, and a Flask host.

```bash
python -m pip install -r requirements.txt
python app.py
```

Open `http://127.0.0.1:5002/`. The generated module is served at
`/static/js/App.js` from `dist/static/js/App.js`.
